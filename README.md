## Run Locally

Node.js 20+ is recommended.

```bash
git clone https://github.com/paarthM007/portfolio-paarthM.git
cd portfolio-paarthM
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
npm run preview
```
